
# 🎓 Système de Gestion des Projets de Fin d'Études

Ce projet est une application web développée pour faciliter la gestion des soutenances de fin d’études à l’Université d’Oran 1.

---

## 🎯 Objectifs

* Automatiser la gestion des soutenances
* Organiser les jurys et les plannings
* Faciliter la communication entre étudiants, enseignants et administration

---

## 👥 Acteurs du système

* 👨‍🎓 **Étudiants (Binôme)** : dépôt des mémoires, consultation des notes et du planning
* 👨‍🏫 **Enseignants** : validation des mémoires, évaluation et notation
* 🏢 **Service pédagogique** : gestion des jurys et création des plannings
* 👨‍💼 **Chef de département** : validation des dates et supervision

---

## ⚙️ Fonctionnalités

* Authentification des utilisateurs
* Dépôt et validation des mémoires
* Création des jurys
* Planification des soutenances
* Évaluation et attribution des notes

---

## 🧠 Conception (UML)

Le système a été modélisé à l’aide de diagrammes UML :

* Diagrammes de cas d’utilisation
* Diagrammes de séquence
* Diagrammes de classes

---

## 🛠️ Technologies utilisées

* HTML, CSS, JavaScript
* PHP
* MySQL / PhpMyAdmin
* Figma (design)

---

## 🚀 Installation

1. Installer XAMPP ou MAMP
2. Importer la base de données dans phpMyAdmin
3. Placer le projet dans le dossier `htdocs`
4. Lancer le projet via `localhost`

---

## 📁 Structure du projet

* `Binome/` → partie étudiant
* `Enseignants/` → gestion enseignants
* `servicePedagogie/` → gestion des jurys
* `chefDep/` → administration
* `UML/` → diagrammes
* `css/`, `images/` → ressources
